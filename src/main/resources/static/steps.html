命令说明（含 SpEL 前序步骤输出示例）

步骤序号从 0 开始。执行第 N 步时，可以在命令或环境变量中用 Spring EL 读取前面已成功步骤的结果：

#{steps[0].output}第 0 步的输出文本
#{steps[0].exitCode}第 0 步退出码
#{steps[0].status}第 0 步状态（SUCCESS）
#{steps[0].name}第 0 步名称
#{steps.size()}前序步骤数量
#{task.autoBranch}本次自动合并分支

等价的系统环境变量（系统注入）：%OB_STEP_COUNT%、 %OB_STEP_0_OUTPUT%、%OB_STEP_0_EXIT_CODE%； bash/sh 使用 $OB_STEP_0_OUTPUT。

示例（hello-world 三步）：

# 步骤 0：编译
javac -encoding UTF-8 -d out/production/hello-world src/HelloWorld.java

# 步骤 1：执行
java -cp out/production/hello-world HelloWorld

# 步骤 2：用第 1 步的输出做期望值验证（Windows cmd）
echo #{steps[1].output} | findstr /C:"Hello, World!"

# bash/sh 写法
echo "$OB_STEP_1_OUTPUT" | grep -q "Hello, World!"

注意：单步“测试”没有前序步骤结果；表达式写错或引用未执行步骤会直接判定该步骤失败； OB_* 系统变量不参与表达式渲染。
